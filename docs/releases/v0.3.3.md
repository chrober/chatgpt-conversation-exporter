# ChatGPT Conversation Exporter v0.3.3

This patch makes optional performance diagnostics less prominent without removing the diagnostic capability or changing its data.

## Changes

- Remove **Save performance report** from the progress/completion panel. The panel now shows **Cancel** while exporting and **Close** throughout.
- Rename the gear dialog to **Export settings** and add a collapsed, accessible **Diagnostics** disclosure.
- After a run succeeds, fails or is cancelled, open **Export settings → Diagnostics → Download performance report** to retrieve the same `chatgpt-export-performance-<timestamp>.json` as before.
- Disable the diagnostics action before a run, while an export is active, or if the current conversation has no recorded metrics. Keep the last settled report available after the progress panel has been closed, without persisting it to disk.
- Prevent access to a different conversation's diagnostics after ChatGPT single-page-app navigation; a new session still starts a fresh profiler.
- Keep the small version display, now showing **v0.3.3**.
- Update English documentation and UI regression tests.

## Compatibility

The **profiling data format, instrumentation and filename are unchanged**. No modifications to pagination, attachments, ZIP packaging, authentication, settings defaults, saved preferences, or auto-update URLs. A performance report is never downloaded automatically.

## Installation

Install the latest [stable userscript from `main`](https://raw.githubusercontent.com/chrober/chatgpt-conversation-exporter/main/userscripts/chatgpt-conversation-export.user.js) or use the attached release asset. Existing v0.3.2 users with automatic updates enabled can receive this release through Tampermonkey's normal periodic update check.

For details, see the [installation and validation guide](https://github.com/chrober/chatgpt-conversation-exporter/blob/main/docs/installation-and-validation.md).
