# ChatGPT Conversation Exporter v0.3.2

Adds explicit, stable automatic-update metadata for **Tampermonkey** and other compatible userscript managers.

## Changes

- New `@updateURL` pointing to a lightweight `.meta.js` on the repository's **`main`** branch.
- New `@downloadURL` pointing to the complete `.user.js` on **`main`**.
- New generated `userscripts/chatgpt-conversation-export.meta.js`: metadata-only header; no executable exporter logic.
- `scripts/build-userscript.js` generates and verifies both files using the **same metadata block**. Version comes from `package.json`.
- CI checks for stale files, update URLs, and synchronized version metadata; release workflow publishes both script and metadata artifacts.
- Updated English documentation describing automatic update checks, upgrade migration and feature-branch isolation.

## Upgrading from older versions

**One manual upgrade to v0.3.2 is recommended**, especially if v0.3.1 or earlier was installed from a version-specific GitHub release, an old feature branch, or by pasting into the editor. Open the [stable main-branch userscript](https://raw.githubusercontent.com/chrober/chatgpt-conversation-exporter/main/userscripts/chatgpt-conversation-export.user.js) or the attached `.user.js` and **update/replace the existing installation**, ensuring there is only one enabled copy. Reload the ChatGPT tab.

Afterwards, Tampermonkey checks the small [main-branch update metadata](https://raw.githubusercontent.com/chrober/chatgpt-conversation-exporter/main/userscripts/chatgpt-conversation-export.meta.js) according to its configured interval. It downloads the full script **only when `@version` increases**. Updates are not immediate, and disabled auto-update settings are respected.

The update source is intentionally **`main`, never a development branch**. If you install a feature-branch copy for experiments, disable auto-updates for that installation to prevent switching back to the stable release.

## Compatibility

No changes to conversation pagination, attachment downloads, ZIP contents, settings defaults or privacy boundaries. The installed version continues to appear in the Settings footer.

## Validation

Automated CI covers metadata generation, identical script/metadata headers, stable URLs and version parity. End-to-end automatic updates still require a live userscript-manager environment and a subsequent higher-version release.
