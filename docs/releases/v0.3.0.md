# ChatGPT Conversation Exporter v0.3.0

This release adds **optional attachment downloading** to the single-conversation JSON/ZIP exporter.

## What's new

- **Include attachments (experimental)** toggle in the gear settings; **off by default**. Its setting remains session-only until **Save**.
- Discover file IDs in message attachment metadata and supported asset pointers, and assistant-generated `sandbox:/mnt/data/...` links.
- Export the validated conversation JSON, successfully retrieved attachment files, and a detailed `attachments-manifest.json` in one ZIP.
- Show downloaded/discovered file counts and preserve a transparent manifest of failed or unavailable files.
- Support the ChatGPT project-aware file download route (`gizmo_id`) and narrowly validated signed media CDN URLs. Cross-origin CDN requests **never receive ChatGPT session cookies or authorization headers**.
- Include sequential cancellation, per-file and total download size limits, sanitized ZIP filenames, and read-only URL verification.
- Keep the previous conversation-only export behavior unchanged when attachments are disabled.
- Extend the offline JSON/ZIP comparison tool to read multi-file ZIP archives; it compares conversation messages, **not binary attachment equality**.

## Validation

- **77 automated Node tests** were passing before the final version bump; final release checks run again on the tagged release commit.
- The original user-uploaded **7z file in a ChatGPT project conversation** downloaded successfully through the userscript in Firefox/Tampermonkey after the project-aware resolver changes.
- Earlier message-level comparisons for a 5,329-record conversation confirmed identical message IDs, canonical message objects and ordering between measured 2-turn and 3-turn export modes.

## Caveats

Attachment retrieval remains **best effort** because ChatGPT download endpoints are undocumented and availability varies by file type, account and retention status. Some user files, assistant sandbox outputs, generated images and expired resources may not be retrievable. The feature is deliberately opt-in, with explicit per-file failure reporting.

At most 100 distinct attachment references are attempted, 50 MiB per file and 200 MiB total. These bounds protect browser memory but can cause larger files to be skipped.

Conversation JSON and attachment manifests can contain personal messages, filenames and message IDs; review ZIPs before sharing them. No sensitive HAR files, signed download URLs or user access tokens are included in this release.

## Install

Use the attached `chatgpt-conversation-export.user.js` asset or [install from the stable main branch](https://raw.githubusercontent.com/chrober/chatgpt-conversation-exporter/main/userscripts/chatgpt-conversation-export.user.js). Update/replace any previous script, avoid duplicate enabled installations, then reload the ChatGPT tab.

Full instructions: [README](https://github.com/chrober/chatgpt-conversation-exporter/blob/main/README.md) and [Firefox validation guide](https://github.com/chrober/chatgpt-conversation-exporter/blob/main/docs/installation-and-validation.md).
