# ChatGPT Conversation Exporter v0.3.1

Small UI update to the settings panel.

## Changes

- Rename the settings option from **Include attachments (experimental)** to **Include attachments** in both the visible label and the accessible checkbox name.
- Show the installed version discreetly at the lower-right of the settings panel (e.g., **v0.3.1**), in a small, muted 10-pixel font.
- Use the same runtime version constant for the settings footer and the privacy-preserving performance report.
- Update English documentation and regression tests.

## Compatibility and limitations

No change to export logic, downloaded file formats, attachment retrieval, defaults, or persistent settings. **Include attachments** remains off by default and is still best effort: some files may be expired, inaccessible or unsupported because the ChatGPT download APIs are undocumented.

## Validation

GitHub Actions checks the generated userscript against the sources and executes UI and ZIP/attachment regression tests. The version displayed in settings is checked against the package version and performance report.

## Installation

Install or update the [official userscript](https://github.com/chrober/chatgpt-conversation-exporter/releases/download/v0.3.1/chatgpt-conversation-export.user.js), disable duplicate active installations if any, and reload the ChatGPT tab.
